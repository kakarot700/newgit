01 THE MISSING LAYER

Git remembers what changed.
NewGit remembers why.

Branches and commit messages were never designed to carry the full story of work shared between people and agents. NewGit makes that story part of the repository.

BUILT ON A FEW STRONG IDEAS

Trust the record.
Not the guess.

A.

Evidence stays honest

Supported checks are recorded explicitly. AI opinions are labeled as AI-generated—not passed off as machine facts.

B.

AI stays optional

The repository workflow works without a model. Agents use the same operations and validation rules as the CLI.

C.

Decisions stay reviewable

Proposals connect rationale, evidence, and approvals. Integration is handled transactionally.
