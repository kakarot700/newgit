# NewGit landing page

Static product site for NewGit. The site is implemented in vanilla HTML, CSS, and JavaScript and is published from this directory using the repository's GitHub Pages workflow. No build step or package dependencies are required.

The workflow deploys `website/` to `https://kakarot700.github.io/newgit/` whenever site files are pushed to `main`. The custom domain `newgit.lovie.me` is configured separately in the repository's Pages settings and requires a matching DNS CNAME at the domain provider.

The landing page describes NewGit as a pre-1.0 production candidate and links to the repository's compatibility, security, known-limitations, and release-readiness documents.
